Seaside backup retention

Seaside keeps hourly incremental backups of each shared and reseller account

for 30 days. A full restore uses the most recent hourly point; a file restore

may pick any hour inside that window.

Restores are requested from Backups. Shared restores usually finish within one

hour. A full-account restore does not take the site offline; Seaside restores

into a staging directory and the account holder publishes it.

There is no VPS product, so there is no disk rollback.
