Seaside PHP version procedure

Shared and reseller accounts default to PHP 8.4. The account holder may switch

among 8.3, 8.4, and 8.5 from Software, then Select PHP version.

A change can be per directory: drop a .php-version file with the major.minor

value in that folder. PHP 8.2 remains available until the last day of the

calendar year and then disappears from the selector.

Seaside does not run PHP 8.1.
